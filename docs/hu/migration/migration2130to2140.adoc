== coffee-tool

* `GZIPUtil` metódusok overload-old verziót kaptak `initialBufferSize` paraméterrel,
így ha van egy becsült kimeneti méreted, nagymértékben csökkentheted a heap garbage keletkezését nagy fájlok esetén.
Valamint a régi metódusok a bemeneti adatokon alapuló heurisztikákat használtak az `initialBufferSize` kiszámításához.
