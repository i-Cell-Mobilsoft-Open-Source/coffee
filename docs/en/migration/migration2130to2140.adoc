== coffee-se-util

* `RandomUtil.generateId` got optimized, now runs a third amount the time it used to

=== Migration
The changes are backwards compatible and do not require any migration.

== coffee-tool

* `GZIPUtil` methods got overloaded versions with `initialBufferSize`, so if you have an estimated output size,
you can greatly reduce heap garbage generation for large files.
Also, the old methods use heuristics based on the input data, to calculate the `initialBufferSize`.

=== Migration
The changes are backwards compatible and do not require any migration.

== coffee-deltaspike-api

* API classes have been extracted from `coffee-deltaspike-data` module to new `coffee-deltaspike-api` module.

=== Migration
The changes are backwards compatible and do not require any migration.
